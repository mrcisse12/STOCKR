Questions fréquentes

Mes données sont-elles perdues si je change de téléphone ?

Non. Allez dans Paramètres → Sauvegarde et enregistrez le fichier. Sur le nouveau téléphone, installez BARO puis importez ce fichier. Si vous êtes connecté à votre compte, vos données se retrouvent automatiquement.

L'application fonctionne-t-elle sans internet ?

Oui. Vous pouvez vendre, ajouter du stock et encaisser hors connexion. Les données se synchronisent dès que le réseau revient.

Pourquoi mon bénéfice est-il négatif ?

Le bénéfice affiché est le bénéfice net : ventes moins dépenses. Si vous avez enregistré une dépense (loyer, perte de produit périmé) sans vente ce jour-là, le résultat est négatif. Touchez la tuile pour voir le détail dans le Bilan.

Comment scanner mes produits ?

Ouvrez le scanner depuis l'écran Stock. Autorisez la caméra quand elle est demandée : elle sert uniquement à lire le code-barres et à photographier le produit. Vous pouvez aussi saisir le code à la main.

À quoi sert l'écran Péremptions ?

Il classe vos produits du plus urgent au moins urgent et calcule l'argent immobilisé dans ce qui va périmer. Vous pouvez solder un produit pour l'écouler, ou le retirer en enregistrant la perte dans votre bilan.

Comment noter ce qu'un client me doit ?

Écran Crédits clients : « Nouveau crédit », le nom et le montant. Quand le client rembourse, même en plusieurs fois, appuyez sur « Encaisser ». « Relancer » envoie un rappel WhatsApp poli.

J'ai oublié mon code PIN

Le code PIN protège l'ouverture de l'application sur votre appareil. Si vous l'oubliez, déconnectez-vous puis reconnectez-vous avec votre e-mail et votre mot de passe pour le redéfinir.

Comment supprimer mon compte et mes données ?

Écrivez-nous à koneribaut@gmail.com depuis l'adresse de votre compte. Tout est effacé sous 30 jours. Pensez à faire une sauvegarde avant si vous souhaitez conserver votre historique.
